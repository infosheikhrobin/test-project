# Test Project

A small Node.js project by Robin.

## Requirements

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm (comes with Node.js)

## Setup

```bash
npm install
```

Copy environment variables into a `.env` file in the project root. This project uses [dotenv](https://github.com/motdotla/dotenv) to load them.
