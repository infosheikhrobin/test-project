# Notes.js

A notes app built with **Next.js** and **TypeScript**.

## Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **UI:** React

## Conventions

- Use TypeScript for all new files (`.ts` / `.tsx`). Avoid plain JavaScript.
- Prefer the App Router (`app/`) over the Pages Router.
- Keep notes-related features (create, list, edit, delete) as the core of the product.
- Colocate components, types, and styles with the feature they belong to.
